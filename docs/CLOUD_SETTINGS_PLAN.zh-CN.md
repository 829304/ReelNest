## 目标与首版方向

让用户在重装或更换设备后恢复应用设置。首版计划支持用户自己的 WebDAV 存储：配置存储地址和凭据，将设置导出为独立配置文件，上传备份，并在另一台设备预览后恢复。

不要求注册 ReelNest 账号，不依赖 ReelNest Server；未开启云备份或存储不可达时，本地应用继续正常使用。第一版以显式备份、选择备份和恢复为目标，自动双向同步留待后续单独设计。

## 数据范围

| 内容 | 计划处理 |
|---|---|
| 主题、语言、界面布局、通用播放和字幕偏好 | 按可移植字段清单备份与恢复；只包含届时实际实现的设置 |
| 媒体服务器地址、来源名称与策略 | 可备份非敏感配置；恢复后验证连接并按需重新登录，不自动扫描或写回媒体 |
| 本地媒体目录、缓存目录、外部播放器路径、设备授权 | 留在本机，或恢复时显式重新选择；不把其他设备路径当成有效授权 |
| 密码、Token、API Key、WebDAV 凭据 | 第一版默认不上传；敏感字段使用明确排除规则，包括地址中嵌入的凭据 |
| 媒体文件、海报缓存、整个 SQLite 数据库 | 不属于设置云备份 |

备份内容由独立设置导入/导出模型定义，不直接上传应用数据目录或数据库。配置文档的格式标识与校验属于备份格式设计，不构成建立开发中间数据库升级链的理由。

## 后续实现与验收要点

- 恢复前显示将应用的配置范围，校验文件格式及字段，先保留可回退的本地设置；解析失败不改变本机配置。
- 上传失败、离线或登录失效应明确报告，不能显示备份成功；同名远程备份已有变更时不静默覆盖。
- 在 Windows/macOS/Linux 验证可移植设置恢复、设备字段保留、凭据排除，以及网络错误和损坏文件。
- 新入口沿用届时已迁移的原版设置页组件与视觉规范；具体页面与交互在实施批次中细化。

## 不随本需求展开的内容

自动双向同步需要另行设计冲突、删除传播与多设备并发规则。密码及 Token 跨设备同步需要单独设计端到端加密和密钥恢复。官方托管账号服务、其他云存储提供方以及通过 WebDAV 扫描/播放媒体，也不属于本次确认的首版范围。

本次仅记录需求与计划，没有新增产品代码、云服务或可用设置入口。
