# 播放队列与播放结束行为

2026-10-09。第一阶段桌面端迁移；Windows 已运行验证，macOS/Linux 尚待原生验收。

## 原版规则

依据 `AppState+ExternalPlayback.videoQueueItems`、`AppState.adjacentItem`、`MediaHierarchyPolicy.orderedChildren`、`PlaybackQueuePolicy` 及其原测试，以及 `PlayerView.handleVideoPlaybackEnd/PlayerEpisodeListPopover/PlayerAdvancedSettingsOverlay`、`AppSettings.VideoPlaybackEndAction`。

- 剧集列表只显示当前集及其后续同系列条目，不是整个系列。季/集为空时按 0 排序，再按标题自然顺序；来源 ID 加父项 ID 隔离系列。
- 手动上一集/下一集使用完整同系列顺序，可回到当前可见队列之前；不循环。没有相邻项时提示第一集/最后一集，保留解码器和当前进度。
- 顶层视频手动相邻项按更新时间倒序排列；电影的自动播放队列仍只有自身，不因按下“下一集”或完成当前电影而扩展为自动连播电影。
- 默认播放结束为“自动下一集”；另外两项为“停在结尾”“关闭窗口”。自动下一集到队列末尾保留结尾画面，关闭经同一保存/重试路径执行。
- 播完先保存完整时长和已看状态。重复 EOF 只处理一次；跳回前段重新播放后可再次处理。旧解码器排队的 EOF 不能推动后来手动选中的影片。

## 实现与安全切换

`features/playback/domain/video_queue.dart` 为独立队列规则；`PlaybackSession` 串行处理手动切换、EOF 和关闭。先重新读取索引/来源、检查目录身份和文件，再暂停并保存当前视频；新解码器实际打开成功后提交切换。缺文件、离线、索引读取或目标解码失败时保留当前会话；保存失败不创建新解码器、不自动切集、不请求关闭窗口。点当前集不重复打开。

队列观看状态按批次读取，不对每行单独查询 SQLite；剧集列表使用懒加载行。切换通知主窗口刷新播放记录。轨道/字幕偏好仍沿同系列父项共享，续播仍采用原版默认回退 5 秒规则。

`player_preferences` 保存全局 `videoPlaybackEndAction`，写入成功才更新选择。新模块表 `media_activity` 按来源/媒体保存更新时间，扫描与播放进度写入维护它；进度、更新时间在同一事务提交，删除来源/条目时外键清理。未产生更新时间事件的现有开发条目暂以文件修改时间排序，未自动补写推测时间；其排序不能视为已与原版更新时间逐项验收。仍只维护当前结构，没有历史迁移链、版本升级或自动清库。

## 界面与验收边界

控制条补上一集/下一集，左右区域各 200、中央间隔 8；队列超过一项才显示“剧集列表”。列表沿原版宽 320、内边距 12、行间距 4、列表高上限 380、选中行/观看说明；当前集位于队列首项，打开即能看到它。

设置沿原入口“播放器设置 → 打开内置播放器设置 → 播放 → 播放行为 → 播放结束”。已迁移弹层/更多设置框架和该行，保留原更多设置 680–900 宽、500–660 高、150 宽侧栏及选择按钮参数。其他设置行、标签页仍待迁移，没有无效占位控件。本批不能称完整播放器设置或 UI 一比一完成；SF Symbols、系统字体、材质、弹层箭头、提示动效与跨平台本地化排序仍待对照。

新增 18 项队列单元/组件回归，全量 156 项通过；Windows 三项原生业务测试覆盖原字幕/音轨及独立窗口场景，并新增真实 EOF 的停在结尾、自动切集、损坏下一集保留解码器、回跳重播和关闭保存。测试生成自己的 AVI/Matroska 和临时数据库，不添加或修改用户媒体库。
