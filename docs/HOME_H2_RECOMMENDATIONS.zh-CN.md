# 首页 H2：视频推荐首批

日期：2026-10-12。接续 [H1](HOME_H1.zh-CN.md)，本批实现每日推荐轮播、剧集推荐和高分精选；搜索、运行状态和首页编排继续按[实施计划](HOME_IMPLEMENTATION_PLAN.zh-CN.md)推进，不称完整首页完成。

## 原版基线

只读参考原 MediaLib HEAD `d94fa15a8139e307c76c36bb07fb9ebe1fa10753`：

- `Views/HomeView.swift`：`HomeOverviewSnapshotBuilder` 的偏好信号、评分、日期种子、多样性、看板排除；`overviewFeaturedItems`、`seriesRecommendationItems`、`highRatedFeaturedItems`、`recentSeriesItems` 的 Vivid 回退；`vividOverviewModuleContent` 的实际可见模块。
- `Views/HomeVividComponents.swift`：轮播、页头、背景、按钮、尺寸和侧边翻页；`WidgetGridMetrics.swift` 的半格高度 `116 × 2 + 14 = 246`。
- `Views/MusicPlayerView.swift` 的 `AlbumPaletteCache`/`AlbumColorPalette` 与 `MusicThemeConfig.swift` 的默认参数：封面采色、中性和彩色分支、发光和背景色。
- `App/AppState.swift` 的 `includesCachedVideo`：系列任一单集缓存有效，即可进入离线系列投影。`HomeVideoProjectionPolicy.swift` 与既有 H1 继续观看查询继续复用。

不调用原 MediaLib 服务端，也不以 TMDB、全库扫描或每张图片下载完成作为推荐的前置条件。

## 规则与数据

`home_recommendation.dart` 为纯规则；仓储读取顶层公共视频及既有续播投影，较大候选的解码和推荐计算分别在后台 isolate 执行。不会把约八万条单集或演员详情读入推荐候选，不对每张卡片遍历全库。

| 投影 | 原版规则及取量 |
|---|---|
| 每日推荐 | 平台评分或个人评分归一化后严格大于 8 的候选优先；不足 3 项才补普通高分候选。最多 7 项；看板为空时用 Vivid 推荐回退，未评级的新库仍能显示内容 |
| 偏好 | 收藏、想看、个人评级、已看/进度、最近播放和高分信号；题材与类型权重、近期衰减参数均沿原实现 |
| 多样性 | 顺序选取并扣减重复类型、题材、来源路径权重；按日期与来源内媒体身份稳定扰动，不使用 Dart `hashCode` 或非确定随机数 |
| 剧集推荐 | 优先高分剧集看板，其次通用推荐中的系列，再按最近更新的系列回退；取量沿原版 12/24 项分支 |
| 高分精选 | 排除通用推荐与高分剧集；非系列候选足够时优先非系列，否则补未完成高分内容。看板为空时沿题材看板及原始评分排序回退 |
| 最近添加剧集 | 接入每日看板的排除、偏好和近期排序，最多 24 项；为空时沿原最近更新系列回退 |
| 题材、离线 | 建立对应看板投影；离线只使用现有缓存仓储检查过路径、文件类型、实际大小的有效清单，并关联系列父项。当前 Vivid 总览没有独立题材/离线模块，不擅自另加入口 |

保留原首页自己的评分归一化：提供方评分在 `0 < rating <= 5` 时乘 2，否则上限 10；个人五星评级上限 5 再乘 2。这是原推荐规则，不修改 Emby 存储的十分制评分。看板与 Vivid 回退分支不同，不能统一改成“全都未看过”或“全部模块互不重复”。

身份始终为 `(sourceId, localId)`；每日哈希编码这个身份并显式模拟原 UInt64 溢出。来源、保险库及后代、相册/音乐、选库过滤先于推荐；同远端 ID 的其他账号不合并。播放、想看与详情在操作前重新校验当前身份和公开范围。

各来源独立加载，保留可用结果；缓存盘异常不阻断在线推荐。午夜及跨天恢复前台使日期投影失效，播放通知与来源/偏好变化更新候选；日期变化不重读数据库。较大计算开始前合并 80 毫秒内的启动依赖变化，已失效的任务不发布结果。悬停和滚动不触发推荐重算。

## 界面与交互

- 总览顺序为页头、每日轮播、统计、剧集推荐、既有观看/想看/收藏、最近剧集、高分精选；无内容模块沿原版隐藏。
- 轮播高度 246、圆角 24、文字左边距 30、标题 28、按钮高 44/圆角 14；最多 7 个分页点，当前点宽 19、其他宽 6。侧边线条箭头位于卡片外侧；Flutter 布局为其保留实际命中区域，避免负偏移后无法点击。
- 每 5 秒自动切换；悬停、减少动态效果、应用后台、非当前路由时暂停。支持分页点、侧箭头、水平拖动和水平滚动，沿原 42 像素阈值和 0.48 秒节流。
- 立即播放与想看复用 H1 动作，系列播放仍准备真实季集，再由既有启动器打开播放器。详情和推荐“查看全部”保留首页分支；推荐集合页保留看板顺序及实际取量，不重新按评分排序。
- 页头文字恢复为原“今天，为你精选了一份片单”，恢复三层静态径向背景。轮播先显示文字和原默认配色，已有背景图通过原有有界缓存队列按需读取；图片失败不影响操作。
- 封面配色按原算法和默认主题参数迁移；读取有界缩略图，只计算当前页，短时保留结果。字体使用当前主题，避免按钮覆盖字体后丢失中文。采样与 AppKit 的原生解码/色彩空间存在平台差异，仍需三端原生视觉对照，不能据组件预览宣称逐像素一致。

本地来源沿目前索引可提供的元数据/个人评级参与；原本地完整元数据模块仍有独立迁移边界，不在首页临时引入另一套刮削器。既有 H1 续播/想看的全量看板重排、下一集跨来源取量及本地化排序边界继续记录，不把推荐三项完成等同于原首页所有投影完全迁移。
