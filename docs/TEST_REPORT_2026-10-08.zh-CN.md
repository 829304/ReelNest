## 发现与处理

首次运行既有测试为 45 项通过、1 项失败。来源 UI 用例仍按旧文件信息弹窗断言单一标题和“关闭”按钮，未跟随海报网格/详情迁移。更新为确认真实媒体卡片、进入详情、检查文件路径并返回，同时保留窄窗口断言；未通过修改产品行为迁就测试。

详情文件状态使用原生异步文件探测。组件测试仅推进 Flutter 虚拟时钟会导致等待超时；现在在路由/数据帧之间让真实 I/O 完成，再检查页面稳定，保留完成条件断言。

旧导航/外观测试只替换了来源列表，新增健康设置使它尝试创建默认数据库，产生多数据库警告。现注入每例独立的内存仓储，确保该类组件测试不依赖开发机数据库或凭据。最终全量运行没有该警告。本轮没有修改业务实现。

## 本轮覆盖

- 在线根目录下的缺失文件与整个来源离线的区别；忽略离线告警不改变安全清理候选。
- 嵌套来源、相邻同前缀目录、最具体离线来源、Windows 大小写与 UNC 路径；重复路径单轮只探测一次。
- 隐私/音乐文件排除、照片文件缺失检查，以及相册/其他视频/非顶层条目的影视元数据排除。
- 封面/年份/简介缺口、取消探测、设置保存后的过期结果丢弃；忽略/恢复只过滤缓存，不再次探测文件。
- 当前初始 SQLite 结构新建、忽略记录去重与重开、来源和媒体身份隔离；健康检测不删除索引。
- 真实临时文件中的系列 NFO、海报相对路径、两个季的父子关联、数据库重开、删除单集后成功重扫清理。
- 空闲保存不扫描；保存中取消原批次、重扫编辑来源并保留追加请求；SQLite 写入失败保留原扫描与队列。

文件集成用例使用独立临时目录与测试数据库；清理前核对临时目录归属，不操作实际媒体库。未建立开发中间数据库升级或兼容测试。

## 后续修复：批量添加与 Windows 隐藏属性

- `addFolders` 返回成功、重复跳过和失败项，目录校验/保存异常不会丢失此前成功项，也不阻止后续目录尝试。页面按成功项原顺序启动扫描并显示部分失败结果；重试只添加和扫描尚未保存的目录。全部重复时保留原提示。
- Windows 扫描通过系统文件属性检查隐藏文件和目录，隐藏目录不进入递归队列。读取每批最多 128 个路径，原生查询在后台 isolate 执行；属性读取失败不发布成功扫描，不更新成功时间或清理旧索引。点号过滤保留，关闭隐藏过滤时跳过属性查询。
- `ffi` 2.2.0 与 `win32` 6.4.0 从既有间接依赖声明为直接依赖，未升级版本。
- 新增 8 项回归：仓储 3 项、来源页面 1 项、隐藏属性/扫描 4 项。覆盖成功—失败—成功、SQLite 保存失败后继续、失败项重试、全部失败、成功项实际进入扫描，以及 Windows 真实 Hidden 属性、中文路径、隐藏目录不递归、开关反转、属性读取失败保护和批次上限。
- Windows 上 `flutter test --no-pub --reporter expanded`：71 项全部通过，包括两项 Windows 原生属性用例；`flutter analyze --no-pub` 无问题。初次分析的一处测试括号格式提示已修正。
- 本批未构建 Release、启动正式应用或验证真实 NAS；Windows 原生属性用例在其他系统跳过，不能据此宣称 macOS/Linux 原生验收完成。
