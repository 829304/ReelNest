# 媒体源别名与 Emby 图标

用户于 2026-10-11 要求侧栏 Emby 媒体源使用 Emby Logo，并增加明确的媒体源别名入口。

- 侧栏来源标题使用工程已有的 `assets/brands/emby.png`，不改变下方各媒体库的图标和名称。
- 在“媒体源”管理页找到来源，点击“设置别名”；Emby 也保留侧栏右键“重命名”。两个入口使用同一个编辑窗口。
- 别名保存在本机 SQLite 的来源名称中，保存后侧栏和媒体源列表一起更新，重启后保留。只改变 ReelNest 内的显示名称，不修改远端服务器、真实文件夹、来源 ID、连接地址或账号凭据。
- 保存时去除名称首尾空白，空名称不能保存。取消不改变原名称；保存失败时保留编辑窗口及输入，可以重试。扫描期间不允许修改来源配置。

原版依据：`ContentView.swift` 的 `EmbySourceRenameSheet` 及侧栏右键重命名入口、`SourcesView.swift` 的远程来源重命名说明。沿用现有 `sources.name`，没有新增数据库版本或迁移分支。

验证覆盖空名称/取消、保存失败后的重试、关闭并重新打开数据库后的持久化，以及 Windows/macOS/Linux 明暗主题下侧栏 Logo 和两个入口的名称联动。组件测试不代表三端原生或真实服务器验收。
