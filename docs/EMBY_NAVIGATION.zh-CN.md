## 原版依据

- `Sources/MediaLib/Views/ContentView.swift`：`EmbyLibrarySection`、`embySourceGroup`、`SidebarMetrics`。按来源分组，显示非空的全部视频/想看/收藏，以及服务端命名库；来源可折叠和右键重命名。音乐和音乐最近播放留给后续模块。
- `Sources/MediaLib/Views/LibraryView.swift`：`LibrarySnapshotBuilder`、`availableSortModes`、`selectSortMode`、浏览状态恢复。搜索延迟 180 ms，按当前目的地筛选、排序；分库使用来源 ID 和库 ID 双重定位。
- `Sources/MediaLib/App/AppState.swift`：`items(for:)`、`searchFields(for:)`、`toggleWatchlist`。想看是本机状态，不调用 Emby 写回接口；收藏/观看沿用已实现的远程痕迹模式。
- `Sources/MediaLib/App/PinyinSearchMatcher.swift`：原子串、拼音和首字母匹配语义。具体搜索平台差异见下文。

## 本批行为

侧栏加入已保存的 Emby 来源。全部视频、想看和收藏只在有对应顶层内容时显示；非音乐的命名库即使为空也保留入口。来源折叠状态写入 SQLite，右键重命名复用原来源设置保存，不触发额外扫描。不同账号/服务器的同名库和同 ID 条目始终隔离。

同步成功时，服务端 Views 目录与媒体快照在同一事务提交。分页、数据库写入或取消失败均保留上次目录和媒体索引。仅浏览、搜索、筛选及修改想看不请求服务器；封面加载仍使用已有鉴权图片入口。图片磁盘缓存、内存缓存及预热随后已接入，见 [画质与缓存](EMBY_QUALITY_CACHE.zh-CN.md) 和 [右键/多选与图片内存缓存](EMBY_LIBRARY_ACTIONS.zh-CN.md)。

浏览只展示顶层视频，按当前库/全部视频/想看/收藏限定范围，再取搜索与类型、观看筛选的交集。搜索覆盖标题、原名、简介、年份、ID、类型、编解码器、清晰度、已缓存详情人物/公司/国家以及子集标题和季集编号。系列可由已同步单集的搜索字段命中，不把单集混入顶层海报墙。超过 180 项的过滤和排序在独立 isolate 执行，海报网格按需构建，不受旧的单页数量限制。

观看筛选沿用全部、正在观看、未观看、已观看、想看和喜欢；使用全局已看阈值，默认 90%，阈值保存会使结果刷新。排序包括最近更新、最近添加、标题、年份、时长、观看进度、评分、评级；时长/评分/评级仅在当前范围有数据时显示。标题默认自然升序，其余默认较新/较大优先；重复选择同项反向，主值相同时标题仍升序。最近添加保留首次入库时间，重同步不覆盖本机想看与初始评级。

排序、方向和观看筛选按来源及目的地分别持久化。搜索和类型不跨应用重启恢复；打开详情后返回保留当前页面的搜索、筛选和位置。详情操作条加入想看/移出想看，读状态尚未完成时禁止错误地以默认值切换。设置写入失败显示错误，不调用无关服务端。

## 仍待迁移与验收

本批不是完整 `LibraryView`：手动集合、公共海报设置/其他布局与原版其他功能仍保留在迁移清单中。批量选择/右键操作和离线缓存筛选已在后续批次接入，见 [右键与多选](EMBY_LIBRARY_ACTIONS.zh-CN.md)。库名/题材/库类型推断已按原 `RemoteLibraryClassificationPolicy` 接入 `IndexedMedia.displayType`，媒体身份和播放类型保持同步器的原始值，见 [评级与分类](EMBY_CLASSIFICATION_RATING.zh-CN.md)。首页和公共分类页仍需消费该投影，当前不能据此视为公共分类页面完成。

中文拼音使用锁定的 [lpinyin 2.0.3](https://pub.dev/packages/lpinyin)，已覆盖常见汉字全拼/首字母与英文词首字母。尚未等效原 `CFStringTransform(.toLatin)` 对全部文字体系、重音和地区排序的处理；当前数字分段自然排序也不能替代完整 `localizedStandardCompare`。这些属于未迁移的一致性项，不视为用户同意降级，后续公共搜索/排序适配需继续补齐。

侧栏使用原 252 宽、22 缩进、11 图文间距、10/9 内边距、12 圆角与 13.5 字号；网格沿用最小 150、列距 20、行距 30。系统字体/SF Symbols、菜单材质、完整主题和动画仍未通过原版逐项视觉验收，不能称一比一完成。

画质切换/Emby 转码、图片缓存/预热、离线下载与字幕缓存已在后续批次接入，下一项按既定顺序推进首页。TMDB 和完整人物推荐属于公共元数据模块；真实 Emby 连接验收继续延后，不将本机模拟服务通过当作真实兼容性通过。

## 2026-10-12：修复系列在“正在观看”中缺失

用户报告首次进入“全部视频”的观看筛选只显示电影。只读检查本机索引发现 32 个单集有播放位置，而 2,664 个系列父条目的位置均为零。此前顶层筛选只检查父条目，遗漏了单集的观看痕迹；连接器也没有保留原 `EmbyService.mediaItem` 已使用的 `UserData.PlayedPercentage`（系列常无 `RunTimeTicks`）。

修复包含两个读取路径：

- 没有时长时按原规则读取服务端观看百分比；有时长时仍使用真实位置/时长。百分比只用于显示和筛选，不捏造时长或播放位置。本机显式清除的零状态优先，不能被远端旧百分比重新恢复；首页的对应读取也沿同一规则处理。
- 快照按同来源系列索引单集记录。“正在观看”保留有观看痕迹且仍有未完成集的系列，包含电视剧、动漫、纪录片和综艺；看完当前集而还有后续集时仍可出现。全部已完成或清除单集历史后移出。单集本身不混入顶层海报墙，也不把单集位置写进系列父记录。

这些投影使用已有索引，在原快照构建阶段一次准备，筛选不新增逐卡网络请求或强制整库扫描。播放窗口通知仍定向刷新来源。只读 SQL 诊断确认本机现有单集数据可恢复 **7 部系列**的观看资格，未更改用户观看状态或清空数据库；该计数不是实际 GUI 点击验收。

新增 4 项回归覆盖四类系列首次加载、按库筛选、电影同时显示、完成/清除后移出、播放通知重新进入，以及无时长百分比持久化、真实位置优先和首页清除保护。全量 **460 项 Dart 测试通过**，静态分析无问题，7 个相关 Dart 文件格式及差异空白检查通过。

Windows Release 以 `lib/main.dart` 重新构建成功（38.0 秒）；09:32:13 +08:00 启动检查观察 5 秒，窗口响应正常、正常关窗、退出码 0，stderr 仅有 Impeller 后端提示。未操作真实 Emby 的播放/筛选界面，正式 EXE 已更新供用户验收；本批没有提交或推送。
