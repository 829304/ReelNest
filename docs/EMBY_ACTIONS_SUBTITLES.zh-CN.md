# Emby 收藏、已看与服务器字幕

日期：2026-10-09。接续 [E3 播放与进度同步](EMBY_PLAYBACK.zh-CN.md)。本批完成电影/剧集的基础状态操作和服务器文本字幕接入，不代表完整 Emby、首页或原版 UI 已完成。

## 原版依据

- `EmbyService.swift`：`setFavorite`、`setPlayed`、`subtitleStreams`、`subtitleDownloadURL`、`subtitleFileExtension`。
- `AppState.swift`：`toggleFavorite`、`markWatched`、`markAllWatched`、`syncEmbyFavorite`、`syncEmbyPlayed`、`scheduleEmbyPlayedSync`。
- `MediaRepository.markWatched`：标记已看保留位置和最后播放日期；标记未看清除位置、进度及最后播放日期。

- `PlayerView` 字幕面板和已有 mpv 外挂/双字幕控制继续复用。原版的服务器字幕下载调用也用于离线缓存；本批仅接入在线播放中的字幕选择，离线视频缓存仍未迁移。

## 已实现

### 收藏与观看状态

- 收藏使用 `POST/DELETE Users/{userId}/FavoriteItems/{itemId}`；已看使用 `POST/DELETE Users/{userId}/PlayedItems/{itemId}`，兼容空响应和 204。
- 只有 `bidirectional` 写回服务器；`importOnly` 和 `disabled` 的手动操作仅更新本机。后续全量同步时 `importOnly` 导入服务器状态，`disabled` 保留已有本地收藏和观看状态，首次导入仍采用服务器初值。
- 收藏先保存本机，写回失败时回滚并提示；已看先完成本机事务，服务器失败保留本机结果，统计失败数并继续上传后续条目。
- 批量操作去重并先校验所有身份，本机保存放在一个事务中。整季/整部剧集遍历全部分页，不局限于当前可见的 60 集或首批 200 集。
- 单项/剧集右键支持标记已看和清除已观看；详情标题旁提供喜欢操作。剧集列表支持全部标记，分季显示时也提供对应季的批量入口。
- 所有读写以来源 ID 和条目 ID 隔离，沿用当前账号的鉴权恢复和一次 401 重试规则。
- 修复来源刷新通知中的重复空事件问题：向 Riverpod 提供递增修订值，使连续收藏/观看修改均能刷新页面。

### 服务器字幕

- 打开播放器字幕面板时获取条目详情，匹配当前 `MediaSourceId`；找不到指定来源时按原版回退到首个来源。
- 筛选有索引的文本字幕，支持 SRT/SubRip、ASS、SSA、VTT/WebVTT，以及服务器明确声明的文本字幕回退。位图字幕继续由视频内部字幕轨道承担，本批不增加转换服务。
- 用户选择后下载并交给真实 mpv `sub-add`，同一播放会话重复选择复用已下载文件/轨道；现有关闭字幕和第二字幕入口继续使用 mpv 轨道。
- 优先使用 `DeliveryUrl`，否则构造 `Videos/{itemId}/{mediaSourceId}/Subtitles/{index}/Stream.{extension}`。使用当前登录令牌替换旧 `api_key`，保留其他查询参数。
- 字幕地址与跳转遵守同源策略；带凭据的地址、跨站地址不转发登录令牌。字幕响应按块累计，超过 8 MiB 立即终止，避免复制原版先完整读入再检查的缺陷。
- 字幕请求包含排队在内最多等待 15 秒；关闭窗口会取消正在等待的字幕操作，过期排队任务不再发送请求。字幕失败保留视频播放，支持重新刷新/选择。
- 下载目录为每次播放生成的独立临时目录。文件名仅用索引、安全语言标识和固定扩展名，不含令牌、服务器地址或用户输入的路径。切集/关闭时先释放解码器，再清理所属临时目录。
- 这不是离线字幕缓存，也不自动下载全部字幕。已选择字幕语言会存入现有偏好，但本批没有实现重新播放时自动下载并恢复服务器外挂字幕；后续完善原版偏好一致性时继续核对。
