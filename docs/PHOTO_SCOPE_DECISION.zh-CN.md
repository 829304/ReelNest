# 照片模块范围调整

2026-10-12，用户明确：“照片我们暂时就不实现了，这个模块可以去掉”。此决定优先于原版完整功能迁移要求，其余功能和界面的一致性约束不变。

## 当前范围

照片/相册浏览、照片查看器、系统照片库、照片搜索、照片元数据和首页照片墙移出当前开发计划与验收范围。不把这些项目继续列为首页或首阶段交付缺口，也不自动排入后续阶段；恢复须用户重新确认。

影视海报、背景图、剧照、演员头像和相应图片缓存继续属于视频功能。音乐仍按已确认的独立模块安排。

## 代码调整

- 本地媒体源分类去掉“照片”，添加和来源设置复用同一分类组件。
- 首页布局枚举与编辑图标去掉照片墙，默认顺序保留其余模块原顺序；添加面板没有照片墙入口。
- Emby 侧栏、视频库快照与选库面板排除 `photos` 类型媒体库。
- 基础照片类型、扫描识别和影视聚合隔离保留，避免将已有照片索引误判为影视。没有删除来源、索引、数据库或磁盘文件，也没有增加历史 schema 升级分支。
