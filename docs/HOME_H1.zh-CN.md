# 首页 H1 实现记录

日期：2026-10-12。当前是视频首页首批实现，不代表原首页所有功能或三端原生验收已经完成。

## 本批能力

- 首页汇总客户端已管理的本地目录、移动盘、已挂载 NAS 与 Emby 视频索引；不依赖原 MediaLib 服务端。
- 影片、系列、单集、未观看统计；继续观看、最近播放、想看、收藏、最近添加剧集。空模块隐藏，无来源显示添加引导，读取/部分索引/来源异常分别显示。
- 卡片进入既有详情，右键播放复用既有启动器；Emby 系列先按需准备单集，再选择续播/下一集。本地想看、收藏补齐持久化与详情入口；Emby 收藏仍写回服务器。
- 横向条带、翻页箭头与自动轮播；查看全部为惰性网格，滚动接近底部继续读取，超过初始 36 项仍可浏览；详情返回保留列表与滚动位置。
- 来源与偏好变化刷新投影；播放器通知按受影响来源刷新首页记录和统计。清除播放记录复用既有历史版本保护，拒绝过期检查点。

首页资格先按来源、选库和保险库后代过滤，音乐和相册不混入视频模块；以 `(sourceId, localId)` 保留来源身份。首页详情与操作再次校验当前公开资格，删除来源、改选库后旧卡片不可继续执行动作。

## 原版对照与实现边界

只读对照 `HomeView.swift`、`HomeVividComponents.swift`、`AppState.rebuildDerivedItemCaches`、`HomeVideoProjectionPolicy`、`MediaPlaybackRecencyPolicy`、`WidgetGridMetrics.swift` 及相关测试。

- 保留原视频模块相对顺序、横向留白 36、纵向留白 28、模块间距 22、海报 158×236、续播卡片 236×138、圆角 18、卡片间距 14；统计高度沿原 `116 × 0.75 = 87`，每条最多展示 12 张卡片。
- 续播候选沿原顶层可播放项目的 `0 < progress < 0.95`；下一集按季/集顺序找最后已完成集之后的项目，使用已看阈值，不按集号简单加一。存在系列/下一集时优先展示这一范围，过滤发生在分页限制之前。
- 最近播放需要真实痕迹，范围沿原公共顶层视频；没有擅自把所有新索引项目或全部单集当作最近播放。下一集和单集自己的记录不等于自动改写系列父记录。
- 原“最近添加 · 剧集”的非推荐板回退按 `updatedAt` 排序，不是“全部影片按首次入库时间”。H2 将迁移原每日推荐板，不能将当前回退称为完整推荐实现。
- SQL 分类匹配保留 SQLite 的 JSON 数组及转义形态；真实题材数组曾导致候选失配，已补空数组和多语言数组回归。

本批不增加新推荐算法或新的首页栏目。每日推荐轮播、剧集推荐、高分精选、全局搜索、运行状态在 H2；首页编排在 H3。音乐与公共集合仍跟随各自模块迁移；照片墙已按用户 2026-10-12 的决定移出当前产品、计划与验收范围，不再作为首页缺口。

UI 已按上述源码参数迁移并进行 Widget 渲染检查，仍需在真实桌面应用中逐项验收主题、字体、材质、完整菜单与动效。SQLite 分页的标题并列项当前使用 `NOCASE`，已载入结果使用既有自然标题比较；分页边界上的本地化自然排序仍需统一核对。下一集候选的跨来源全局取量也需继续对照原推荐板，不能把本批称为逐像素、全部行为一致的最终版本。

## 数据与性能

文件职责：`features/home/domain/home_snapshot.dart` 保存首页模型与合并规则；`data/home_repository.dart` 查询 SQLite；`application/` 管理投影、刷新和动作；`presentation/` 装配首页、查看更多、详情保护与卡片。公共本地想看/收藏保存在 `features/library/`，复用已有偏好表，没有新增开发版本升级链。

不订阅 Emby 完整视频快照，不逐卡拉取详情。查询主要返回有上限的卡片或分组统计，数据库仍使用现有后台连接。无索引且未完整同步的 Emby 来源只请求一页前台候选，不发起整库扫描；已有缓存不触发该请求。部分索引会明确说明统计尚未补齐。

在本机 **92,130 条**真实索引上，用 `mode=ro` 和 `PRAGMA query_only=ON` 单次执行相同 SQL 形态，未输出账号/媒体名称或修改本机数据：

| 查询 | 返回行数 | 耗时 |
|---|---:|---:|
| 分类分组与候选键准备 | 2,680 | 343.0 ms |
| 分组统计 | 2,692 | 1,225.1 ms |
| 续播/下一集首批 | 2 | 1,325.1 ms |
| 最近播放首批 | 9 | 280.6 ms |
| 收藏首批 | 0 | 299.0 ms |
| 想看首批 | 0 | 254.3 ms |
| 最近添加剧集首批 | 36 | 293.5 ms |

这是 Python SQLite 查询诊断，含相应查询取回数据的时间，分类分组项还包含候选准备；不是 Flutter 首帧、Dart 映射、真实网络速度或滚动帧率。各查询仍有数据库工作量，大库首屏没有固定毫秒承诺；后续可以沿数据版本减少重复聚合。
