# 首页百分比进度与清除提示修复

## 确认的问题

Emby 同步会为电影、单集等非系列内容建立 `playback_states`，即使服务器只提供 `PlayedPercentage`、没有位置和时长。首页过去以本地位置是否为 NULL 决定百分比回退，零值同步记录会使续播、统计与推荐丢失有效进度。

首页清除记录调用 `markPlayed` 后忽略写回失败数量。该仓储保留本地成功结果并捕获逐项网络错误，所以外层异常提示无法通知用户服务器未更新。此外，只有百分比而没有位置/日期的记录此前会在清除前被当成无历史跳过。

## 修复

- 在现有 `player_preferences` 中按完整媒体身份保存本地播放状态来源标记；播放保存、标记观看及主动清除与标记写入处于同一事务。不修改初始表结构、不添加数据库升级、不清除用户数据。
- 首页及 Emby 视频库按标记区分本地覆盖与同步空记录：有有效时长时仍优先使用位置/时长；缺少时长且没有本地覆盖时允许回退服务器百分比。继续观看、统计、推荐候选和系列播放目标使用一致的进度规则。
- 允许导入播放痕迹时，远程索引写入在同一事务移除本地覆盖标记；禁用痕迹导入时保留。独立的历史清除 epoch 始终保留，重新同步后也不允许旧播放器检查点恢复已清除记录。
- 清除操作认可未被本地覆盖的百分比痕迹；明确清除后的零值记录不再因旧元数据重新视为待清除记录。
- 首页检查写回失败数量，提示本机播放记录已清除、远程写回失败，以及后续同步可能恢复服务器记录。导入模式不发起服务器写回，成功写回不显示失败提示。

## 回归

新增两项数据库回归与四项本机 HTTP fixture 组件回归，覆盖：

- 真实索引写入生成的零位置/零时长电影记录及百分比续播、历史、统计和推荐；主动清除与本地播放优先级。
- 禁用导入保留清除、重新导入恢复服务器状态、清除 epoch 与旧检查点隔离。
- 仅百分比单集的系列播放目标选择。
- 首页双向同步的写回成功/失败及导入模式；检查实际提示、本地结果与 Emby 视频库投影。
