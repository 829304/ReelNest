## 源码依据与范围

- `EmbyService.swift` 的 `fetchItemDetail`、`fetchExtras`、媒体映射：用户条目详情、前 28 名演职员、角色名称、图片索引、制作地区/公司、分级、状态、提供方 ID 及媒体技术字段。
- `AppState.loadDetailSnapshot`：详情缓存有效期 30 天；刷新失败保留已有详情；详情请求不重新导入收藏和观看状态。
- `DetailView.swift`：简介与元信息、详情分区位于季集/文件区之前，详情失败不阻止播放。
- `MediaTMDBExtrasView.swift`：详情折叠、主创后演员、艺术照、相关链接；人员卡片宽 88、头像 72、横向间距 14；艺术照宽 220、海报宽 104、缩略图请求宽 500。
- `MediaImageViewer.swift`、人物详情视图：图片计数、切换、缩放、底部缩略图及人物库中作品入口。

## 实现

详情协议与展示模型放在 `api/emby/emby_detail.dart`，接口仍为当前账号的 `Users/{userId}/Items/{itemId}`。按来源串行鉴权，并沿用一次 401 恢复。技术信息优先匹配当前播放资源，回退第一个资源；保存视频/音频编码、分辨率、容器、码率、大小和时长。

`EmbyDetailRepository` 管理当前初始表 `remote_media_details`。主键为来源 ID 与条目 ID，外键随条目删除；不添加开发版本迁移或清除用户数据。缓存只保存选定展示字段和图片身份，不保存原始响应、资源路径、字幕地址或鉴权 URL。详情也不覆盖索引标题、库范围、收藏、播放进度和已看状态。

页面先显示已有缓存，过期才更新；无缓存时基础信息与播放立即可用，详情单独加载。失败保留旧数据并提供重试。请求的 15 秒预算包括排队时间，离开页面会取消；过期任务不会在队列恢复后发送。网络结束后事务再次确认条目存在，防止移除过程中重建缓存。

详情新增服务器简介、类型标签、分级、状态、制作公司和技术信息。主创/演员支持点击查看人物与当前来源已缓存的库中作品。艺术照包含全部服务器背景图和海报，支持全屏预览、左右键切换、双击缩放、拖动、底部缩略图和 Escape 关闭。图片由来源身份获取当前鉴权数据，沿用按块限制大小和解码尺寸限制；网络/解码失败显示占位，不中断详情。

2026-10-21 性能补充：`cachedPersonWorks` 仍优先命中同来源会话缓存；未命中时按关联 ID 批量读取作品和父剧集，不再逐条查询 `sources.media`。保留来源/媒体库范围、父剧集去重和既有关联顺序，不扩大人物作品覆盖范围。1000 条剧集关联回归固定 4 次 SELECT；完整证据见[演员作品批量读取与偏好增量刷新](LIBRARY_INCREMENTAL_READS_2026-10-21.zh-CN.md)。

相关链接沿用豆瓣、IMDb、TMDB、维基百科入口，通过系统浏览器打开。搜索文字作为查询参数编码；IMDb/TMDB 仅接受合法提供方 ID，链接使用固定站点，服务器资源令牌不传入外部浏览器。
